# Privacy

Whole Page Capture is local-first by design.

## What it accesses

The extension receives temporary access to the current tab only after you choose **Capture full webpage** from that page's right-click menu. It reads the page dimensions, scrolls the page, captures visible tiles, and combines those tiles into the PNG you requested.

## What it does not do

- No page content, screenshot, URL, or title is sent anywhere.
- No analytics, telemetry, ads, accounts, tracking, or remote services exist.
- No browsing history is stored.
- No screenshot history is stored.
- No permanent website access is requested.

The last plain-language result is held in browser session memory so the toolbar popup can explain whether the capture succeeded or failed. That status disappears when the browser closes and never contains the page URL, title, content, or image.
